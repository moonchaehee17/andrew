# 부산남부경찰서 수사8팀 사건관리

팀원 관리와 사건 진행상황 점검을 위한 **설치 불필요 웹앱**입니다.
파일 하나(`사건관리.html`)만 있으면 되고, 인터넷 연결 없이 동작합니다.

---

## 1. 설치 및 실행

1. 이 저장소에서 **`사건관리.html`** 파일 하나만 내려받습니다.
2. 사무실 PC의 원하는 폴더(예: `내 문서\수사8팀`)에 저장합니다.
3. 파일을 **더블클릭**하면 브라우저에서 바로 열립니다. (Chrome 또는 Edge 권장)
4. 브라우저 주소창 옆 ⭐ 또는 `Ctrl+D`로 즐겨찾기에 등록해 두면 편합니다.

> 별도 프로그램 설치, 서버 구동, 관리자 권한이 필요 없습니다.

---

## 2. 데이터 보관과 백업 — **반드시 읽어주세요**

- 입력한 모든 자료는 **이 PC의 브라우저 안에만** 저장됩니다. 외부로 전송되지 않습니다.
- 다만 **브라우저 방문기록 / 인터넷 사용기록을 삭제하면 자료도 함께 지워집니다.**
- 그래서 **주 1회 백업**을 권합니다. 우측 상단 `백업` 버튼 → `team8-backup-날짜.json` 파일이 내려받아집니다.
- 마지막 백업 후 7일이 지나면 화면 상단에 안내 띠가 자동으로 뜹니다.
- 복원: `팀원 · 설정` 탭 → `백업 파일 복원` → 저장해 둔 json 파일 선택.
- PC를 교체하거나 다른 PC에서 이어서 볼 때도 이 백업 파일로 그대로 옮길 수 있습니다.

### 개인정보 관련
정식 수사기록(KICS)이 아닌 **팀 내부 진행관리용 도구**입니다.
피의자·고소인 실명이나 주민등록번호는 입력하지 마시고 `김○○` 형태로 적으시기 바랍니다.
사건번호와 죄명만으로도 진행관리에는 지장이 없습니다.

## 3. 화면 구성

### 대시보드
- **진행 중 사건 / 10건 초과 인원 / 점검 필요 항목 / 이번 달 종결** 4개 지표
- **팀원별 보유 사건**: 신호등으로 표시 (초록 = 여유, 노랑 = 목표 근접, 빨강 = 목표 초과)
  - 팀원 카드를 클릭하면 그 사람 사건만 걸러서 볼 수 있습니다.
- **진행 국면별 분포**: 5개 국면 + 세부 단계로, 어디에 사건이 몰려 있는지 한눈에 확인
  (막대를 클릭하면 그 단계 사건만 걸러 볼 수 있습니다)
- **점검 필요 사건**: 아래 3가지를 자동으로 잡아냅니다.
  - 처리기한 임박(기본 D-7) 또는 기한 경과
  - 같은 단계에 오래 머문 정체 사건(기본 14일 이상)
  - 팀장 의견을 달았는데 담당자가 아직 확인하지 않은 사건

### 사건 목록
담당자 · 단계 · 진행/종결 상태로 거르고, 접수번호 · 죄명 · 당사자 · 메모를 검색할 수 있습니다.
긴급 사건이 항상 위로 올라오고, 그 다음은 기한이 빠른 순입니다.

### 사건 상세

수사 진행 **21단계 트래커**를 5개 국면으로 묶어 보여줍니다.

| 국면 | 단계 |
|---|---|
| 접수 · 분석 | 1. 접수 → 2. 사건분석(범죄사실·구성요건 정리) → 3. 관할 검토 |
| 고소인 조사 | 4. 고소인(진정인)·피해자 조사 → 5. 사건재분석(수사방향 결정) |
| 자료 확보 | 6. 강제수사 필요성 검토 → 7. 금융계좌추적용 압수수색영장 신청 → 8. 영장 집행·거래내역 분석 → 9. 계좌명의자 특정·관할 재검토 → 10. 임의제출·수사자료 확보 |
| 피의자 수사 | 11. 참고인 조사·객관자료 분석 → 12. 피의자 특정·출석요구 → 13. 체포영장 신청 → 14. 통신사실확인자료 제공요청 → 15. 체포영장 집행·검거 → 16. 피의자 조사(피의자신문) |
| 종결 절차 | 17. 사건종합검토(진술 대조·혐의 판단) → 18. 추가 수사 → 19. 수사결과보고서 작성 → 20. 사건당사자 통지 → 21. 종결 |

**단계 번호를 클릭**하면 그 단계가 현재 진행 단계가 되고, 앞의 단계는 자동으로 완료 처리됩니다.
각 단계의 완료일이 기록되어 어디서 얼마나 지체됐는지 남습니다.
잘못 눌렀으면 완료된 단계에 마우스를 올려 `이 단계로 되돌리기`를 누르면 됩니다.

#### 선택 단계 — 사건마다 거치지 않는 절차
`선택` 표시가 붙은 7개 단계(계좌추적 영장 3개, 체포영장·통신영장 3개, 추가 수사)는
사건에 따라 거치지 않습니다. 마우스를 올려 **`완료`** 또는 **`해당없음`** 을 누르면 되고,
`해당없음` 처리한 단계는 진행률 계산에서 빠집니다.

- 계좌추적이 필요 없어 6번에서 10번으로 바로 넘어가면, 7~9번은 **자동으로 `해당없음`** 처리됩니다.
- 다만 그 절차를 이미 시작한 경우(예: 영장을 신청해 둔 상태)에는 임의로 지우지 않고
  **`미처리`** 로 표시해 두므로, `완료`인지 `해당없음`인지 직접 고르시면 됩니다.

#### 이송 분기
3번 `관할 검토`와 9번 `계좌명의자 특정·관할 재검토`에는 **분기** 표시가 붙어 있습니다.
타 관서 관할로 확인되면 곧바로 21번 `종결`을 눌러 종결 구분을 **`타관서 이송`** 으로 선택하면 됩니다.

#### 종결 구분
21번 `종결`을 누르면 **송치 / 불송치 / 수사중지 / 타관서 이송** 중에서 고르게 됩니다.
선택한 구분은 사건 목록·주간 보고에 그대로 표시됩니다.

#### 팀장 의견
`사건분석`·`사건재분석`·`사건종합검토` 세 단계에는 `팀장 검토` 표시와 함께 작성 버튼이 항상 보입니다.
(다른 단계에도 마우스를 올리면 작성할 수 있습니다.)
담당자가 `확인 처리`를 누르기 전까지 대시보드에 미확인으로 남습니다.

수사 메모는 자유롭게 기록하고 `메모 저장`을 누르면 됩니다.

### 주간 보고
현재 상황을 그대로 회의자료 형태로 만들어 줍니다.
`인쇄 / PDF 저장` 버튼으로 출력하거나 PDF로 저장할 수 있습니다.
(담당자별 보유·정체·기한임박 요약표 + 담당자별 사건 목록 + 최근 7일 종결 내역)

### 팀원 · 설정
- 전체 21단계 구성표(팀장 검토 · 선택 · 분기 표시)를 한 화면에서 확인
- 팀원 계급·성명 수정, 추가, 삭제
  - 보유 사건이 있는 팀원은 삭제되지 않습니다. 전출 시 **재직 체크만 해제**하면 됩니다.
- 관리 기준 조정: 목표 보유 건수(기본 10), 주의 기준(기본 9), 정체 기준 일수(기본 14), 기한 임박 일수(기본 7)
- 백업 / 복원 / 엑셀(CSV) 내보내기 / 가져오기 양식 내려받기

## 3-1. 엑셀로 사건 한꺼번에 등록하기

이미 엑셀로 관리하시던 사건 목록이 있으면 그대로 불러올 수 있습니다.

1. 우측 상단 **`엑셀 불러오기`** 를 누르고 `.xlsx` 또는 `.csv` 파일을 고릅니다.
2. **열 연결** — 머리글 이름을 보고 자동으로 짝을 지어 줍니다. 틀린 곳만 바꾸면 됩니다.
   - 인식하는 머리글: 접수번호(사건번호·번호), 죄명(죄종·사건명), 담당자(담당·수사관),
     사건구분, 접수일, 처리기한(수사기일), 고소인(진정인·피해자), 피의자, 진행단계, 중요도, 비고(메모)
3. **확인** — 실제로 등록될 내용이 표로 나옵니다.
   - <span>빨간 행</span> = 접수번호·죄명이 모두 비어 있어 **제외**되는 행
   - <span>노란 행</span> = 접수번호가 이미 있는 **중복** 행 (기본은 건너뜀, 체크를 풀면 함께 등록)
   - 담당자 이름을 못 알아본 행은 지정한 기본 담당자에게 배당되고 원래 값이 옆에 표시됩니다
4. `N건 가져오기`를 누르면 등록됩니다. 목표 건수를 넘긴 팀원이 있으면 바로 알려 줍니다.

알아서 처리되는 것들:
- **날짜** — `2026-08-26`, `2026.8.26`, `20260826`, 엑셀 날짜서식(일련번호) 모두 인식합니다.
- **담당자** — `송당호`, `경사 배지혜` 처럼 계급이 붙어 있어도 찾아냅니다.
- **진행 단계** — 단계 이름(`피의자 조사`)이나 번호(`16`) 어느 쪽이든 됩니다. 비어 있으면 `접수`로 시작합니다.
- **한글 깨짐** — CSV가 엑셀 기본 인코딩으로 저장돼 있어도 자동으로 다시 읽습니다.

어떤 형식으로 만들지 모르겠으면 `팀원 · 설정` 탭의 **`가져오기 양식 내려받기`** 를 눌러
견본 파일을 받아 채워 넣으시면 됩니다.

## 4. 권장 운영 방식

| 시점 | 할 일 |
|---|---|
| 사건 접수 즉시 | `+ 사건 접수`로 등록(여러 건은 `엑셀 불러오기`). 담당자 선택 화면에 각자 현재 보유 건수가 표시되므로 적은 사람에게 배당. 목표(10건)를 넘기면 등록 직후 경고가 뜹니다. |
| 사건분석 단계 | 팀장이 상세 화면에서 `＋ 팀장 의견 작성`으로 수사 방향 지시 |
| 매일 아침 | 대시보드의 `점검 필요 사건`만 확인 (보통 몇 건 안 됩니다) |
| 주간 회의 | `주간 보고` 탭 인쇄 → 그대로 회의자료 |
| 매주 금요일 | `백업` 버튼 한 번 |

## 5. 기술 사항

- 단일 HTML 파일 (외부 라이브러리·네트워크 요청 없음)
- 저장소: 브라우저 `localStorage` (키: `nambu-team8-case-mgmt-v1`)
- 내보내기: JSON(전체 백업), CSV(엑셀용, UTF-8 BOM 포함)
- 가져오기: `.xlsx` 는 브라우저 내장 `DecompressionStream` 으로 직접 해제해 시트를 읽습니다
  (외부 라이브러리·네트워크 불필요). 첫 번째 시트를 읽고, 첫 줄을 머리글로 봅니다.
- 기존 11단계 자료는 앱을 열 때 21단계 체계로 **자동 이관**됩니다(접수번호 항목 포함).
- 확인된 동작 환경: Chromium 계열(Chrome, Edge) — `file://` 로 직접 열어도 저장·복원·엑셀 읽기 정상 동작

향후 팀원들이 각자 PC에서 접속해 입력하는 **공유형**으로 전환할 경우,
지금의 데이터 구조(JSON 백업 파일)를 그대로 옮겨갈 수 있도록 설계되어 있습니다.
