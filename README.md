# 부산남부경찰서 수사8팀 사건관리

팀원 관리와 사건 진행상황 점검을 위한 **설치 불필요 웹앱**입니다.
파일 하나(`사건관리.html`)만 있으면 되고, 인터넷 연결 없이 동작합니다.

---

## 1. 설치 및 실행

1. 이 저장소에서 **`사건관리.html`** 파일 하나만 내려받습니다.
2. 사무실 PC의 원하는 폴더(예: `내 문서\수사8팀`)에 저장합니다.
3. 파일을 **더블클릭**하면 브라우저에서 바로 열립니다. (Chrome 또는 Edge 권장)
4. 브라우저 주소창 옆 ⭐ 또는 `Ctrl+D`로 즐겨찾기에 등록해 두면 편합니다.

> 별도 프로그램 설치, 서버 구동, 관리자 권한이 필요 없습니다.

---

## 2. 데이터 보관과 백업 — **반드시 읽어주세요**

- 입력한 모든 자료는 **이 PC의 브라우저 안에만** 저장됩니다. 외부로 전송되지 않습니다.
- 다만 **브라우저 방문기록 / 인터넷 사용기록을 삭제하면 자료도 함께 지워집니다.**
- 그래서 **주 1회 백업**을 권합니다. 우측 상단 `백업` 버튼 → `team8-backup-날짜.json` 파일이 내려받아집니다.
- 마지막 백업 후 7일이 지나면 화면 상단에 안내 띠가 자동으로 뜹니다.
- 복원: `팀원 · 설정` 탭 → `백업 파일 복원` → 저장해 둔 json 파일 선택.
- PC를 교체하거나 다른 PC에서 이어서 볼 때도 이 백업 파일로 그대로 옮길 수 있습니다.

### 개인정보 관련
정식 수사기록(KICS)이 아닌 **팀 내부 진행관리용 도구**입니다.
피의자·고소인 실명이나 주민등록번호는 입력하지 마시고 `김○○` 형태로 적으시기 바랍니다.
사건번호와 죄명만으로도 진행관리에는 지장이 없습니다.

## 3. 화면 구성

### 대시보드
- **진행 중 사건 / 10건 초과 인원 / 점검 필요 항목 / 이번 달 종결** 4개 지표
- **팀원별 보유 사건**: 신호등으로 표시 (초록 = 여유, 노랑 = 목표 근접, 빨강 = 목표 초과)
  - 팀원 카드를 클릭하면 그 사람 사건만 걸러서 볼 수 있습니다.
- **단계별 분포**: 어느 단계에 사건이 몰려 있는지 한눈에 확인
- **점검 필요 사건**: 아래 3가지를 자동으로 잡아냅니다.
  - 처리기한 임박(기본 D-7) 또는 기한 경과
  - 같은 단계에 오래 머문 정체 사건(기본 14일 이상)
  - 팀장 의견을 달았는데 담당자가 아직 확인하지 않은 사건

### 사건 목록
담당자 · 단계 · 진행/종결 상태로 거르고, 사건번호 · 죄명 · 당사자 · 메모를 검색할 수 있습니다.
긴급 사건이 항상 위로 올라오고, 그 다음은 기한이 빠른 순입니다.

### 사건 상세
- 수사 진행 **11단계 트래커**
  1. 접수 → 2. 사건분석 → 3. 고소인(진정인) 조사 → 4. 사건재분석
  → 5. 영장신청 / 피의자 출석요구 → 6. 피의자 조사 → 7. 사건종합검토
  → 8. 추가 수사 → 9. 수사결과보고서 작성 → 10. 사건당사자 통지 → 11. 종결
- **단계 번호를 클릭**하면 그 단계가 현재 진행 단계가 되고, 앞 단계는 자동으로 완료 처리됩니다.
  각 단계의 완료일이 자동 기록되어 어디서 얼마나 지체됐는지 남습니다.
- 잘못 눌렀으면 완료된 단계에 마우스를 올려 `이 단계로 되돌리기`를 누르면 됩니다.
- **팀장 의견**은 `사건분석`·`사건재분석`·`사건종합검토` 세 단계에 작성할 수 있습니다.
  (`팀장 검토` 표시가 붙은 단계) 담당자가 `확인 처리`를 누르기 전까지 대시보드에 미확인으로 남습니다.
- 수사 메모는 자유롭게 기록하고 `메모 저장`을 누르면 됩니다.

### 주간 보고
현재 상황을 그대로 회의자료 형태로 만들어 줍니다.
`인쇄 / PDF 저장` 버튼으로 출력하거나 PDF로 저장할 수 있습니다.
(담당자별 보유·정체·기한임박 요약표 + 담당자별 사건 목록 + 최근 7일 종결 내역)

### 팀원 · 설정
- 팀원 계급·성명 수정, 추가, 삭제
  - 보유 사건이 있는 팀원은 삭제되지 않습니다. 전출 시 **재직 체크만 해제**하면 됩니다.
- 관리 기준 조정: 목표 보유 건수(기본 10), 주의 기준(기본 9), 정체 기준 일수(기본 14), 기한 임박 일수(기본 7)
- 백업 / 복원 / 엑셀(CSV) 내보내기

## 4. 권장 운영 방식

| 시점 | 할 일 |
|---|---|
| 사건 접수 즉시 | `+ 사건 접수`로 등록. 담당자 선택 화면에 각자 현재 보유 건수가 표시되므로 적은 사람에게 배당. 목표(10건)를 넘기면 등록 직후 경고가 뜹니다. |
| 사건분석 단계 | 팀장이 상세 화면에서 `＋ 팀장 의견 작성`으로 수사 방향 지시 |
| 매일 아침 | 대시보드의 `점검 필요 사건`만 확인 (보통 몇 건 안 됩니다) |
| 주간 회의 | `주간 보고` 탭 인쇄 → 그대로 회의자료 |
| 매주 금요일 | `백업` 버튼 한 번 |

## 5. 기술 사항

- 단일 HTML 파일 (외부 라이브러리·네트워크 요청 없음)
- 저장소: 브라우저 `localStorage` (키: `nambu-team8-case-mgmt-v1`)
- 내보내기: JSON(전체 백업), CSV(엑셀용, UTF-8 BOM 포함)
- 확인된 동작 환경: Chromium 계열(Chrome, Edge) — `file://` 로 직접 열어도 저장·복원 정상 동작

향후 팀원들이 각자 PC에서 접속해 입력하는 **공유형**으로 전환할 경우,
지금의 데이터 구조(JSON 백업 파일)를 그대로 옮겨갈 수 있도록 설계되어 있습니다.
